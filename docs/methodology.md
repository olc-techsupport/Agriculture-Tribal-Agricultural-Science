# Methodology and decision record

Notebooks 01–07 provide public-data regional context in dependency order. Their sources have different spatial and temporal support; none represents Tribal knowledge, jurisdiction, or operational conditions. Pine Ridge is the primary instructional focus. Other Nations and geographies are contextual comparisons only.

The system stress index is exploratory. Every component must record availability, provenance, geography, period, unit, and transformation. Missing groundwater, vegetation, drought, or agricultural data remains unknown and must not receive a neutral value. Scores may be compared only when periods and component availability match. Thresholds are transparent examples pending scientific and local review.

The local pipeline validates schemas and ranges; it does not grant permission, implement governance, authorize collection, or publish data. The dashboard and spreadsheet templates are inactive evaluation prototypes. Before use, the governing Nation must approve purpose, collective benefit, steward, infrastructure, users, fields, retention, prohibited uses, location handling, incident procedures, derived outputs, and publication authority.

Generated public artifacts should record generation time, Git revision, inputs, outputs, and checksums. Presence in `outputs/` is not scientific or governance approval.
