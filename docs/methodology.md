# Methodology and decision record

Notebooks 01–07 provide regional public-data context in dependency order. Their sources have different spatial and temporal support; none represents Tribal knowledge or jurisdiction. Generated artifacts record generation time, Git revision, and input/output checksums.

The SSI is exploratory. Every component must carry availability and provenance. Missing groundwater, vegetation, drought, or agricultural data remains unknown and must not receive neutral stress. Comparisons require matching component availability and periods; thresholds require local review before operational use.

The local operational pipeline validates schema/ranges and records a manifest; it does not grant permission or publish data. Before deployment, document governing Nation, steward, approved purposes/users, retention, prohibited uses, aggregation/location rules, incident contact, and publication authority. Until then, the dashboard is local evaluation software only.
