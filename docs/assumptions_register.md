# Assumptions register

| Assumption or value | Current role | Status |
|---|---|---|
| Census boundaries represent instructional study context | Public-data mapping | Statistical only; not jurisdiction |
| County NASS statistics represent Tribal agriculture | Regional context | Proxy only; cannot support Nation-specific conclusions |
| MODIS NDVI represents pasture condition | Vegetation context | Proxy requiring field/local validation |
| NOAA climate divisions represent Pine Ridge conditions | Drought context | Regional proxy |
| USGS well coverage represents groundwater conditions | Monitoring context | Coverage limitation; absence is not condition evidence |
| PDSI/NDVI combination represents system stress | Exploratory index | Unapproved analytical construct |
| Pasture scores, animal-condition scores, grazing-pressure values, and action labels | Prototype configuration | Unapproved examples; not operational triggers |
| Climate model/scenario results represent local future conditions | Projection context | Requires ensemble, baseline, bias, and uncertainty review |

Each item needs an appropriate citation, geographic applicability check, and locally authorized review before use beyond instruction or exploratory screening.
